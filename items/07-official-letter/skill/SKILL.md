# كتاب رسمي بالفصحى من حكيك العادي

## 1. اسأل بس عن الناقص الضروري
لازم يكون عندك: **لمين** (الجهة أو المنصب) · **شو الطلب** · **السبب** · **اسم المرسل**.
إذا واحد منهم ناقص، اسأل عنه بسؤال واحد. أي إشي ثاني (رقم وظيفي، تاريخ، مرفقات) إذا موجود بتحطه، وإذا مش موجود بتتركه.

## 2. اكتب الكتاب
- فصحى رسمية واضحة، بلا مبالغة ولا جمل محفوظة طويلة.
- **لا تخترع:** ولا اسم، ولا تاريخ، ولا رقم، ولا سنة، ولا تفاصيل (طبية أو غيرها) مش بكلام المستخدم. إذا ما في سنة، اكتب «القادم». إذا ما في اسم للمسؤول، اكتب المنصب بس.
- فقرة أو فقرتين: الطلب أول، وبعده السبب، وبعده أي معلومة بتساعد (مدة الخدمة، الرقم الجامعي…).
- **اللقب:** إذا المستخدم ما حدد، استخدم «حضرة … المحترم/ة». وخلّي اللقب نفسه بكل الكتاب: لا تكتب «حضرة» فوق و«عطوفتكم» تحت.
  الألقاب الشائعة بالأردن (لما المستخدم يطلبها): معالي (وزير) · عطوفة (أمين عام، مدير عام، محافظ) · سعادة (مدير، رئيس قسم، نائب). إذا مش متأكد، «حضرة».

## 3. اعمل ملف Word
اكتب `letter.json` بالشكل اللي بأول `scripts/kitab.py`، وبعدين:
```bash
pip install python-docx  # إذا مش موجودة
python3 scripts/kitab.py letter.json كتاب.docx
```
السكربت بيرتب الكتاب من اليمين لليسار: الرقم والتاريخ عالشمال، المرسل إليه عاليمين، الموضوع بالنص، التوقيع عالشمال. الخط الافتراضي Arial (موجود بالويندوز والماك)، وبتغيّره بـ `--font`.

## 4. سلّم
الملف + نص الكتاب بالرد (للي بدهم ينسخوه). وذكّر المستخدم يعبّي الرقم والتاريخ إذا الجهة بتطلبهم.
