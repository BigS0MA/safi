## ليش «مجرّب» مش كلمة تسويق
كل عنصر بيمرّ على نفس البروتوكول ([RUBRIC.md](RUBRIC.md)):
1. 3 مدخلات مختلفة على الأقل (فصحى، لهجة، نص فوضوي)، فيها فخاخ مقصودة.
2. مفتاح الإجابة بينكتب **قبل** التشغيل.
3. مقارنة مع الطلب العادي اللي بيكتبه الناس.
4. 6 معايير ثابتة، والنتيجة بتنكتب زي ما طلعت، ومعها حدود التجربة.
5. جولة أخيرة على ChatGPT وClaude المجانيين قبل النشر.

## البنية
```
items/<NN>-<slug>/
  item.json   العنوان، الوصف، الخطوات، النصيحة، ونتيجة التجربة
  prompt.md   النص اللي بينسخ (أو skill/ للسكيلز، بينضغط zip وقت البناء)
  TEST.md     التجربة: شو جرّبنا، النتيجة، شو تعلمنا، الحدود، وسجل التعديلات
  tests/      المدخلات ومفتاح الإجابة ونصوص التشغيل كاملة
  result.png  (اختياري) لقطة من النتيجة الحقيقية، بتطلع بصفحة العنصر
build.py      بيبني site/ من items/ (بلا مكتبات خارجية)
site/         الموقع (Netlify بيبنيه وبينشره)
```

## إضافة عنصر
1. انسخ مجلد عنصر موجود وغيّر الرقم.
2. جرّبه حسب `RUBRIC.md` واكتب `TEST.md`.
3. `python3 build.py`، وافتح `site/index.html` من خلال سيرفر محلي (`python3 -m http.server -d site`).
